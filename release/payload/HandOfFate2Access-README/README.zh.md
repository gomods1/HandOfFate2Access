# Hand of Fate 2 Access

一个让《Hand of Fate 2》无需视力也能游玩的模组。游戏显示的一切都会通过你的屏幕阅读器朗读，而实时部分（战斗、钟摆、转盘、机会牌洗牌）则借助新增的声音提示变得可以凭听觉游玩。

它是对已被放弃的“Hand of Fate 2 Accessibility Mod”的重建，基于前作的模组 Hand of Fate Access。

## 要求

- Windows。
- Hand of Fate 2（Steam 版）。
- 屏幕阅读器（NVDA、JAWS 等）。没有屏幕阅读器时，模组会使用 Windows 内置的语音。

## 安装

最简单的方法是使用每个发布版附带的安装程序 `HandOfFate2AccessibilityInstaller.exe`：它通过 Steam 找到游戏，安装或更新模组，也可以卸载。它支持读屏软件。手动安装的方法：

1. 把发布版 zip 解压到 Hand of Fate 2 的文件夹（包含 `Hand of Fate 2.exe` 的那个；默认 Steam 安装位置为 `C:\Program Files (x86)\Steam\steamapps\common\Hand of Fate 2`）。允许合并文件夹。
2. 启动游戏。启动几秒后你会听到“Hand of Fate 2 Access 版本 ... 已加载”。

zip 中包含已配置好的模组加载器（BepInEx）。

## 工作方式

Hand of Fate 2 本身就支持完整的键盘和手柄导航；模组负责朗读。用游戏自带的操作（方向键，Enter 或空格确认，Tab 返回，Escape 打开暂停菜单）在菜单、卡牌和选项之间移动，每个项目都会说话：

- 卡牌朗读名称、类型、数值以及每个特性及其规则文本。提供给你的装备会与你正穿戴的装备进行比较。
- 遭遇朗读标题、故事文本、结果（“+7 食物”）和选项，包括选项旁印着的花费或条件，以及该选项是否不可选。
- 发牌人和角色的配音台词会以你的语言完整朗读，无论游戏的字幕设置是否开启。
- 底栏的问题（“装备战士之斧？是，否”）出现时会被朗读。
- 挑战目标在出现、改变、完成或失败时都会被朗读。
- 一局结束时会先宣布游戏自身的判定（伤重或饥饿而死、放弃、挑战失败），然后是结果。
- 对话、战斗操作教程（附每个动作的按键）、生物介绍以及角色定制（出身、徽记，以及每种发型和服装颜色的描述）都会被朗读。
- 食物、金币、声望和生命的变化会在发生时播报。
- 进入界面时会念出界面名称（主菜单、地图、挑战地图、牌组编辑器、物品栏、暂停、结果）。物品栏还会说出每个栏位里有什么，包括空栏位，因为游戏的光标会跳过空栏位。
- 一局结束时的计分表（无尽模式）会连同列名逐行朗读。
- 商店：每件商品朗读价格（“37 金币”），买不起时会提示；执行具体操作的确认动作（“购买，Enter”）会连同按键播报。
- 功能键上的动作（F1 物品栏、F3 地图、角色界面的 F3 完成、牌组编辑器的 F3 开始）出现时会连同按键播报。物品栏会说明 Tab（游戏的返回键）可将其关闭。
- 在遭遇中，数字键 1 到 9 可直接选择选项（游戏功能）。
- 挑战地图：每个挑战朗读名称以及是否锁定（附解锁条件）、是否完成、是否已获得金或银代币；战役、冒险、无尽和篝火会说明当前显示的是哪一个（篝火中有更改外观的界面）。打开挑战会朗读其标题和描述。
- 设置：每一行朗读名称和值（列表、复选框、滑块、按键绑定），更改时会念出新值。
- 挑战结束时翻开的奖励牌在揭示时逐张朗读。
- 牌组编辑器：每个牌组说出名称、用途和装满程度（“遭遇，13 张中的 13 张”）；进入后，左右在可用卡牌或你的牌组中移动（上下在两者间切换），每张卡牌说出名称、种类和数值（Ctrl + 上读出其余内容）；确认即添加或移除，并念出新的数量。
- 底栏的问题会说出键盘上的按键名（“离开，Tab；接受骰子，F3”）。按键名以你的语言朗读。

## 模组新增的按键

- **F4**：当前界面的帮助，先是该界面的游戏按键，然后是模组按键。上下方向键逐条朗读；F4 或 Tab 关闭。（F1 是游戏自己的物品栏键。）
- **Ctrl + 上 / Ctrl + 下**：逐行朗读当前焦点项目的详情。卡牌会被简短播报（名称、种类、数值），其特性和规则在这里。任何地方都可用，包括战斗中。
- **Ctrl + 左 / Ctrl + 右**：切换 Ctrl + 上下朗读的内容：**详情**（焦点项目）、**事件**（迄今播报过的一切，最新在前：遭遇文本、问题、战斗开始、生命警告、结果）和**状态**（生命、食物、金币、声望、中毒以及各栏位的装备）。空列表会被跳过。
- **H**（或斜杠，或按下右摇杆）：你的生命、食物、金币、声望和中毒。
- **O**：当前挑战的目标。
- 地图上的 **Shift + 方向键**（或右摇杆）：一个勘察光标，逐张走遍整个可见棋盘，朗读每张牌、你是否在那里、能否移动过去、是否是出口，以及从它延伸出去的方向。它只朗读；移动请用游戏自带的方向键和 Enter。随后 Ctrl + 上可完整朗读勘察的那张牌。
- 地图上的 **Shift + 句号**：勘察光标跳到下一张你尚未访问的牌，从最近的开始；**Shift + 逗号** 回到上一张。每次朗读最后会说出这张牌相对你的位置以及它在列表中的序号（“未访问 2/5”）；最后一张之后会从最近的一张重新开始。已经进入过的商店等牌不再计入。它和 Shift + 方向键一样只朗读。
- 战斗中的 **C**（或按下左摇杆）：从最近敌人的方向发出一声提示音。敌人清空后，它改为指向剩下要走到的地方（出口、首领收缩的圆圈、掉落的金币或食物），或者说“没有敌人了”。
- **可以终结的敌人**：被击倒的敌人会从倒地的位置发出上扬的嗖声，越靠近重复得越快，直到它站起来。走过去按游戏的终结键。最近的敌人可以终结时，**C** 会用这个嗖声代替平常的提示音回应。 一旦终结能够命中（足够近，并且在你推动或面朝的方向上），嗖声上会多一声清脆的叮：朝声音方向推动，马上按终结键。最近的敌人在攻击范围内时，**C** 也会用这声叮回应。

## 凭听觉战斗

- 战斗以敌人数量开始（“战斗，3 个敌人”），数量变化时会念出。生命降到一半、四分之一和十分之一以下时会念出。
- **金属撞击声**：可以反击的攻击。按防御。游戏只把攻击和防御绑定在鼠标按钮上，所以模组为它们分配了按键：**V 攻击，B 防御**（除非你在设置、控制、绑定输入中指定自己的按键）。播报会念出键盘按键，使用手柄时则念出手柄按钮。
- **爆裂声**：无法格挡的攻击。闪避（空格）。
- **风声**：墙壁。靠近某一侧的墙时那一侧的风会变大；一声撞击表示你撞到了墙。
- 投射物、地面危险、光束和陷阱各有自己的声音，总是位于危险所在之处：远离那个声音。
- 一声钟鸣表示武器（左）或神器（右）的能力再次就绪。
- **被缠住**：当敌人缠住你时（地精群、法师的束缚），你会听到“被缠住了”以及需要连续按下的键，直到听见“挣脱了”。其间受到的小伤害就是束缚本身。
- **护甲**：有些敌人（韦斯特温德的恐怖、腐化的敌人）穿着只有**猛击**才能伤到的护甲（默认键盘 E、手柄 B；没有按键时模组会加上 X）。沉闷的金属声表示你的攻击被弹开了；每个敌人第一次时还会听到“有护甲，使用猛击”和按键。碎裂声表示猛击打裂了护甲；哗啦声和“护甲已破”表示你的攻击重新造成全额伤害；上扬的闪光声表示护甲正在恢复（修复中较轻，破碎的护甲恢复时较响，并说“护甲已恢复”）。每个声音都来自那个敌人，并且在设置中有单独的音量。游戏的眩晕操作在整个模组中都叫猛击，与游戏卡牌上一致。
- 如果战斗太难，游戏的学徒模式（设置，常规；死亡几次后游戏也会主动提议）会自动进行反击和终结并提高你的伤害。无论开不开，模组都一样工作。
- 在以出口结束的战斗（陷阱房）中，出口会从通往它的可行走路径的下一个拐角发出提示音，因此朝着提示音走就能绕过墙壁到达出口；掉落的金币和食物以更轻的声音同样发出提示。
- 朝你所站的那条道射击的陷阱（箭、飞镖）会播放爆裂声：快移动。

暂停菜单底部有一个新选项 **声音词汇表**：用方向键浏览以听取每种声音的含义，Enter 播放，Tab 关闭。

## 小游戏

- **机会牌**：牌被展示，每张有自己的音调，并从其位置念出结果，随后洗牌时每张牌的音调会跟随它。选择你跟踪的位置；牌会读作“位置 1”“位置 2”……
- **钟摆**：摆动时你会听到光束下方的结果随之左右移动：越高越亮越好。在你想要的音调上按确认；聚焦时会提醒你这一点。
- **转盘**：摆好时会朗读转盘上的牌；旋转时每个扇区以其结果的声音滴答掠过；按确认使其减速。停在哪里会被念出。
- **骰子**：按确认投掷（否则游戏需要鼠标拖拽）。目标、每次投掷的总点数和各骰点数以及是否达到目标都会被念出；可重掷的骰子朗读其点数和是否已标记，标记时会播报。F3 重掷。

## 语言

模组跟随游戏的语言：游戏的十二种语言全部覆盖（游戏本身说的一切始终是你的语言）。本 README 在 `docs` 文件夹中有每一种语言的版本，包括 Markdown 和 HTML（`docs/README.<语言>.md` 和 `docs/html/README.<语言>.html`）。
