# Hand of Fate 2 Access

Hand of Fate 2 を視覚なしで遊べるようにするモッドです。ゲームが表示するものはすべてスクリーンリーダーで読み上げられ、リアルタイムの部分（戦闘、振り子、ルーレット、チャンスカードのシャッフル）は追加の効果音によって耳で遊べるようになります。

放棄された「Hand of Fate 2 Accessibility Mod」を、前作のモッドである Hand of Fate Access を土台に作り直したものです。

## 必要なもの

- Windows。
- Hand of Fate 2（Steam 版）。
- スクリーンリーダー（NVDA、JAWS など）。ない場合、モッドは Windows 内蔵の音声合成を使います。

## インストール

いちばん簡単なのは、各リリースに添付されているインストーラー `HandOfFate2AccessibilityInstaller.exe` です。Steam からゲームを見つけ、モッドのインストールや更新、アンインストールができます。スクリーンリーダーで操作できます。手動でインストールする場合：

1. リリースの zip を Hand of Fate 2 のフォルダー（`Hand of Fate 2.exe` があるフォルダー。標準の Steam インストールでは `C:\Program Files (x86)\Steam\steamapps\common\Hand of Fate 2`）に展開します。フォルダーの統合を許可してください。
2. ゲームを起動します。起動から数秒後に「Hand of Fate 2 Access バージョン ... を読み込みました」と聞こえます。

zip には設定済みのモッドローダー（BepInEx）が含まれています。

## 仕組み

Hand of Fate 2 にはもともとキーボードとコントローラーによる完全な操作があり、モッドはそれを読み上げます。ゲーム本来の操作（矢印キー、Enter またはスペースで決定、Tab で戻る、Escape でポーズメニュー）でメニュー、カード、選択肢を移動すると、各項目が話します。

- カードは名前、種類、能力値、そして各特性をルール文とともに読み上げます。提示された装備は、今身に着けているものと比較されます。
- エンカウンターはタイトル、物語の本文、結果（「+7 食料」）、選択肢を読み上げます。選択肢の横に印刷されたコストや条件、選べない選択肢であることも含みます。
- ディーラーや登場人物の音声セリフは、ゲームの字幕設定のオン・オフにかかわらず、あなたの言語で全文読み上げられます。
- 下部バーの質問（「戦士の斧を装備しますか？ はい、いいえ」）は表示されたときに読み上げられます。
- チャレンジの目標は、表示、変更、達成、失敗のたびに読み上げられます。
- ランの終わりはゲーム自身の判定（負傷死や餓死、降参、チャレンジ失敗）で告げられ、その後に結果が続きます。
- ダイアログ、戦闘操作のチュートリアル（各操作のキー付き）、クリーチャーの紹介、キャラクターのカスタマイズ（出身、紋章、各髪型と衣装の色の説明）が読み上げられます。
- 食料、ゴールド、名声、体力の変化はその場で告げられます。
- 画面名は入ったときに読み上げられます（メインメニュー、マップ、チャレンジマップ、デッキビルダー、インベントリ、ポーズ、結果）。インベントリは空のスロットも含めて各スロットの中身を読み上げます。ゲームのカーソルは空のスロットを飛ばすためです。
- ラン終了時のスコア表（エンドレス）は、列の名前とともに一行ずつ読み上げられます。
- ショップ：各商品は価格（「37 ゴールド」）を読み上げ、買えないときはそう告げます。具体的な動作をする決定操作（「購入、Enter」）はキー付きで告げられます。
- ファンクションキーの操作（F1 インベントリ、F3 マップ、キャラクター画面の F3 完了、デッキビルダーの F3 開始）は、現れたときにキー付きで告げられます。インベントリは Tab（ゲームの戻るキー）で閉じることを告げます。
- エンカウンターでは数字キー 1 から 9 で選択肢を直接選べます（ゲームの機能）。
- チャレンジマップ：各チャレンジは名前と、ロック中か（解除条件付き）、クリア済みか、金または銀のトークンを獲得済みかを読み上げます。キャンペーン、アドベンチャー、エンドレス、焚き火はどれが表示中かを告げます（焚き火には外見変更画面があります）。チャレンジを開くとタイトルと説明が読まれます。
- 設定：各行は名前と値（リスト、チェックボックス、スライダー、キー割り当て）を読み上げ、変更すると新しい値が読まれます。
- チャレンジ終了時にめくられる報酬カードは、明かされるたびに読み上げられます。
- デッキビルダー：各デッキは名前、用途、充填状況（「エンカウンター、13 枚中 13 枚」）を告げます。中では左右で利用可能なカードまたは自分のデッキを移動し（上下で切り替え）、各カードは名前、種類、能力値を告げます（Ctrl + 上で残りを読みます）。決定で追加または削除され、新しい枚数が読まれます。
- 下部バーの質問はキーボードでのキー名を告げます（「立ち去る、Tab。ダイスを受け入れる、F3」）。キー名はあなたの言語で読まれます。

## モッドが追加するキー

- **F4**：今いる画面のヘルプ。まずその画面でのゲームのキー、次にモッドのキー。上下矢印で一項目ずつ読み、F4 または Tab で閉じます。（F1 はゲーム自身のインベントリキーです。）
- **Ctrl + 上 / Ctrl + 下**：フォーカスされているものの詳細を一行ずつ読みます。カードは短く告げられ（名前、種類、能力値）、特性やルールはここにあります。戦闘中を含めどこでも使えます。
- **Ctrl + 左 / Ctrl + 右**：Ctrl + 上下が読む対象を切り替えます。**詳細**（フォーカス中のもの）、**イベント**（これまでに告げられたすべて、新しい順：エンカウンターの文、質問、戦闘開始、体力警告、結果）、**ステータス**（体力、食料、ゴールド、名声、毒、各スロットの装備）。空のリストは飛ばされます。
- **H**（またはスラッシュ、または右スティック押し込み）：体力、食料、ゴールド、名声、毒。
- **O**：現在のチャレンジの目標。
- マップでの **Shift + 矢印**（または右スティック）：見えている盤面全体をカードごとに巡る探索カーソル。各カードについて、自分がそこにいるか、移動できるか、出口か、どの方向に道が続くかを読みます。読むだけです。移動はゲーム本来の矢印キーと Enter で行います。その後 Ctrl + 上で探索したカードを全文読めます。
- マップでの **Shift + ピリオド**：探索カーソルが、まだ訪れていない次のカードへ近い順に移ります。**Shift + カンマ**で前のカードに戻ります。読み上げの最後に、自分から見たカードの位置と一覧での順番（「未訪問 2/5」）を伝えます。最後のカードの次は最も近いカードに戻ります。すでに入った店などのカードは数えません。Shift + 矢印と同じく、読むだけです。
- 戦闘中の **C**（または左スティック押し込み）：最も近い敵の方向からビープ音。敵がいなくなると、代わりに残りの目的地（出口、ボスの閉じていく円、落ちたゴールドや食料）を指し示すか、「敵は残っていません」と告げます。
- **とどめを刺せる敵**：倒れた敵は、起き上がるまで、倒れている場所から上がっていくシュッという音を鳴らし続けます。近づくほど速くなります。近づいてゲームのとどめのキーを押してください。最も近い敵にとどめを刺せるときは、**C** がいつもの音の代わりにこの音で答えます。 とどめが決まる状態（十分に近く、押している方向か向いている方向にいる）になると、シュッという音に高い澄んだ音が重なります。音の方向へ押しながら、すぐにとどめのキーを押してください。最も近い敵が届く範囲にいるときは、**C** もこの音で答えます。

## 耳で戦う

- 戦闘は敵の数（「戦闘、敵 3 体」）で始まり、数が変わると読み上げられます。体力は半分、四分の一、十分の一を下回ったときに読まれます。
- **金属音**：カウンターできる攻撃。防御を押します。ゲームは攻撃と防御をマウスのボタンにしか割り当てていないため、モッドがキーを与えます。**V で攻撃、B で防御**です（設定、操作、入力の割り当てで自分のキーを割り当てた場合を除く）。アナウンスはキーボードのキー、コントローラー使用時はそのボタンを読み上げます。
- **破裂音**：ブロックできない攻撃。回避（スペース）します。
- **風**：壁。壁に近づくほどその側の風が強まり、ドンという音は壁にぶつかったことを表します。
- 飛び道具、地面の危険、ビーム、罠にはそれぞれ固有の音があり、常に危険のある場所から鳴ります。音から離れてください。
- チャイムは武器（左）またはアーティファクト（右）の能力が再び使えることを知らせます。
- **拘束**：敵がしがみついたとき（ノーム の群れ、魔術師の拘束）、「拘束されました」と、「解放」と聞こえるまで連打するキーが読まれます。その間に受ける小さなダメージは拘束そのものです。
- **装甲**：一部の敵（ウェストウェンドの恐怖、堕落した敵）は、**バッシュ**でしか傷つかない装甲を着ています（初期設定ではキーボードの E、コントローラーの B。キーがない場合は MOD が X を追加します）。鈍い金属音は攻撃がはじかれたことを示し、敵ごとに最初の一回は「装甲あり、バッシュを使う」とキーも読み上げます。砕ける音はバッシュで装甲にひびが入ったこと、砕け散る音と「装甲破壊」は攻撃がまた全部通ることを示します。上がっていくきらめきは装甲が再生していることを示します（修復中は小さく、壊れた装甲が戻ると「装甲回復」とともに大きく鳴ります）。どの音もその敵の方向から鳴り、設定で専用の音量を変えられます。ゲームのスタン操作は、ゲームのカードと同じく、MOD ではすべてバッシュと呼びます。
- 戦闘が難しすぎる場合、ゲームの見習いモード（設定、一般。何度か死ぬとゲームからも提案されます）がリポストととどめを自動化し、与えるダメージを増やします。モッドはどちらでも同じように動作します。
- 出口で終わる戦闘（罠の部屋）では、出口への歩ける道の次の曲がり角から出口がピンと鳴るので、音に向かって歩けば壁を回り込んで出口に着きます。落ちたゴールドや食料も、より軽い音で同じように鳴ります。
- 自分が立っているレーンに撃ってくる罠（矢、ダーツ）は破裂音を鳴らします。動いてください。

ポーズメニューの一番下に新しい項目 **サウンド用語集** があります。矢印で巡って各音の意味を聞き、Enter で再生、Tab で閉じます。

## ミニゲーム

- **チャンスカード**：カードが示され、それぞれ固有のトーンとともに結果がその位置から読まれ、シャッフル中は各カードのトーンがそのカードを追いかけます。追った位置を選びます。カードは「スロット 1」「スロット 2」…と読まれます。
- **振り子**：揺れている間、光の下にある結果が左右に動きながら聞こえます。高く明るいほど良い結果です。欲しいトーンのところで決定を押します。フォーカスするとそのことが案内されます。
- **ルーレット**：配置されたときにルーレット上のカードが読まれ、回転中は各区画が結果の声でカチッと通り過ぎます。決定を押すと減速します。止まった場所が読まれます。
- **ダイス**：決定を押して投げます（本来はマウスのドラッグが必要です）。目標、各投げの合計と出目、目標に達したかが読まれます。振り直せるダイスは値とマーク済みかを読み、マークすると告げられます。F3 で振り直します。

## 言語

モッドはゲームの言語に従います。ゲームの十二言語すべてに対応しています（ゲーム自身が話す内容は常にあなたの言語です）。この README は `docs` フォルダーにすべての言語で、Markdown と HTML の両方で用意されています（`docs/README.<言語>.md` と `docs/html/README.<言語>.html`）。
